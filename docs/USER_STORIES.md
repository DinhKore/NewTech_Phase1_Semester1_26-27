# DANH SÁCH KỊCH BẢN NGƯỜI DÙNG & MA TRẬN TRUY VẾT (TRACEABILITY MATRIX)

**Dự án:** Trợ lý Học tập AI (Course Assistant)  
**Học kỳ:** 1 (2026 - 2027)  
**Quy mô nhóm:** 01 thành viên (Solo)  
**Mục tiêu:** Ma trận truy vết chi tiết 15 User Stories (US01 – US15) từ Yêu cầu -> API Endpoint -> Lớp Mã nguồn (Layered Architecture) -> Kiểm thử (Automated Tests).
